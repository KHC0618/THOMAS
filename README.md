# THOMAS

THOMAS는 개발자 본인을 위해 개발되고 있는 개인용 전자비서다.

현실적으로 구현 가능한 범위에서 자비스와 같은 개인 전자비서를 만드는 것에서 시작한 프로젝트다.

현재는 사용자와 같은 시간 속에서 지속적으로 존재하며 경험을 기억하고, 상황을 이해하고, 판단하고, 필요하면 먼저 말하며, 자신의 판단을 계속 수정해 나가는 하나의 시스템을 지향한다.

---

이 저장소는 THOMAS의 공개 기록이다.

실제 개발과 소스 코드는 비공개 저장소에서 관리한다.

이곳에는 외부에 남길 수 있는 범위에서 개발 이력, 버전 변화, 설계 판단, 수정 기록, 스크린샷과 실제 동작 기록 등을 축적한다.

소스 코드, 상세한 내부 구현, 사용자 데이터와 개인적인 내부 상태는 공개하지 않는다.

THOMAS의 개발에는 GPT와 OpenAI Codex가 적극적으로 사용되고 있으며, 관련 사실 역시 숨기지 않는다.

---

THOMAS의 개발은 계속 진행 중이다.

시간이 지나면서 이 저장소 역시 함께 축적된다.
